## 📌 เนื้อหาสำคัญในแดชบอร์ด (Features)

1. **ติดต่อ Vendor & ทำเนียบตัวแทนจำหน่าย (๕๖ รายการหลัก)**:
   - ๑. มุมมองตารางรายการสินค้า (๕๖ รายการ) พร้อม Brand, Model, ตัวแทนจำหน่ายทางการ, เลขประจำตัวผู้เสียภาษี ๑๓ หลัก (Tax ID), รหัส UNSPSC และเกณฑ์ราคากลาง ม.๔ กรมบัญชีกลาง
   - ๒. มุมมองแยกเฉพาะบริษัทตัวแทนทางการ (Authorized Dealers)
   - ๓. มุมมอง Vendor ทั้งหมด (๓๖ บริษัท) พร้อมประวัติใบเสนอราคาเดิมและร้านคู่เทียบสเปก
2. **ระบบสืบค้นข้อมูลจัดซื้อภาครัฐ (e-GP Database Matching)**:
   - ตรวจสอบสถานะการลงทะเบียนผู้ค้าภาครัฐในระบบ e-GP กรมบัญชีกลาง
   - ปุ่มคัดลอกเลขประจำตัวผู้เสียภาษี (Tax ID) เพื่อนำไปค้นหาใน e-GP ทันที
   - อ้างอิงเกณฑ์การกำหนดราคากลางตาม พ.ร.บ. จัดซื้อจัดจ้างฯ พ.ศ. ๒๕๖๐ มาตรา ๔
3. **เอกสารดาวน์โหลดสำหรับงานพัสดุ**:
   - `ลำดับครุภัณฑ์_พร้อมรายชื่อVendorและข้อมูลติดต่อ_ปี71.docx` (ตารางขยาย ๕๖ รายการ พร้อมสเปกและ Vendor)
   - `ทำเนียบนามบัตร_Vendor_ครุภัณฑ์ปี71_สำหรับงานพัสดุ.docx` (นามบัตรสำหรับติดต่อฝ่ายจัดซื้อ/พัสดุ)
   - `ลำดับครุภัณฑ์_พร้อมรายชื่อVendorและข้อมูลติดต่อ_ปี71.xlsx` (ไฟล์ Excel ตาราง ๕๖ รายการ)
   - `ทำเนียบตัวแทนจำหน่ายครุภัณฑ์_ประเทศไทย.xlsx` (ทำเนียบ ๓๖ บริษัทตัวแทนจำหน่าย)
4. **ภาพรวมแผนครุภัณฑ์ & เล่มหลักสูตร มคอ.๒**:
   - คำขอปี ๗๑ (๙๘ แถว)
   - ความต้องการวิจัยคณาจารย์ GenZ (๕๘ รายการ)
   - รายการครุภัณฑ์ตามเกณฑ์สภาเภสัชกรรม ๗/๒๕๕๘ (๗๑ รายการ)
   - เล่มหลักสูตร มคอ.๒ ฉบับสมบูรณ์ (๒๒๔ นก. / ๑๗ PLOs)
